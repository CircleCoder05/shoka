## 基本块和流图

### 基本块

- 基本块中的代码是连续的语句序列
- 程序的执行（控制流）只能从基本块的第一条语句进入
- 程序的执行只能从基本块的最后一条语句离开
- 符合上述条件的最大块

### 算法

首先确定**入口语句**（每个基本块的第一条语句）的集合

- 整个语句序列的第一条语句属于入口语句
- 任何能由条件/无条件跳转语句转移到的第一条语句属于入口语句
- 紧跟在跳转语句之后的第一条语句属于入口语句

**每个入口语句直到下一个入口语句**，或者程序结束，它们之间的所有语句都属于同一个基本块

### 流图

流图是一种有向图 G（V,E）

- 图的节点V： <基本块>组成的集合
- 图中B1-B2的边：B2的执行紧跟在B1之后

我们称B1为B2的前驱，B2为B1的后继

- 从B1的最后一条语句有条件或者无条件转移到B2的第一条语句；或者
- 按照程序的执行次序，B2紧跟在B1之后，并且B1没有无条件转移到其他基本块

## 局部优化

### 代数性质

- 编译时完成常量表达式的计算（常量折叠），整数类型与实型的转换

- 下标变量引用时，其地址计算的一部分工作可在编译时预先做好（运行时只需计算“可变部分”即可）

- 运算强度削弱：用一种需要较少执行时间的运算代替另一种运算，以减少运行时的运算强度时、空开销

  ```
  x**2 → x*x
  3*x → x+x+x
  8*x , 4*x 等换成左移运算
  x/2 , x/16 等换成右移运算
  x:=x+1 变为 INC x 指令
  x/5 → x*0.2 等
  ```

### 复写传播

如 `x=y` 这样的语句称为复写语句，由于 x 和 y 取值相同，当满足一定条件时，在该复制语句下面出现的 x 可以用 y 来替代，如果是 `x=3` 则这种形式，则称为常量传播

```
x=2
u=4+x # u=6
```

### 窥孔优化

窥孔优化关注在目标指令的一个较短的序列上，通常称其为“窥孔”

通过删除其中的冗余代码，或者用更高效简洁的新代码来替代其中的部分代码，达到提升目标代码质量的目的

窥孔优化并不局限在同一个基本块中

### 消除公共子表达式

例如 `a = b * (-c) + b * (-c)`，通常使用 `DAG` 法消除公共子表达式

DAG图：**有向无环图**，表示基本块内各中间代码之间的关系

## DAG法

![image-20251129220314392](https://circlecoder05.oss-cn-beijing.aliyuncs.com/test/202511292203457.png)

图的 **叶节点** 由变量名或常量所标记（对于基本块内先引用再赋值的变量，可以采用变量名+下标 0的方式，命名其初值）

图的 **中间节点** 由中间代码的操作符所标记，代表着基本块中一条或多条中间代码

基本块中的**变量**的最终计算结果都对应着图中的一个节点，具有初值的变量，其初值和终值可以对应不同的节点

### 生成DAG图

输入：基本块内的中间代码序列

输出：完成局部公共子表达式删除后的 DAG 图

方法：

- 图/节点表初始化：节点表，记录变量名和常量值，及当前对应的DAG图中的节点序号，初始状态为空

- 顺序遍历每一条中间代码，按照以下规则建立 DAG 图

- 形如z = **x** op **y**：在节点表中查找x （对y也做处理，对应j）
  - 如果找到，记录x 所对应的节点号 i
  - 如果未找到，在DAG图中新建叶节点（编号i），标记为x如果x为变量名，该标记更改为x0，在节点表中增加新的表项(x, i)

- z = x **op** y：寻找/创建左操作数为 i、右操作数为 j 的DAG节点，其标记为op，假定其节点编号为k，将节点 i 和 j 分别与 k 相连，作为其左子节点和右子节点

- **z** = x op y：在节点表中寻找z
  - 如果找到，将 z 所对应的节点号更改为 k；

  - 如果未找到，在节点表中新增表项(z, k)

- 对输入的中间代码序列依次重复上述步骤

对函数，数组，指针不进行优化，做保守处理，形如 `x=a[i], a[j]=y, z=a[i]` ，如果 `i == j` 则此时 x 和 z 的值不相同，我们无法简单确定能否对 x 和 z 做代码优化，所以我们一律不做优化

![image-20251129211530204](https://circlecoder05.oss-cn-beijing.aliyuncs.com/test/202511292115335.png)

- 对于 t1 = - c，新增 ( c , 1 )
- 对于 t1 = - c，新增 ( - , 2 )，并将其与 c（1号结点）相连
- 对于 t1 = - c，新增 ( t1 , 2 )
- 对于 t2 = b \* t1，找到了 ( t1 , 2 )，新增 ( b , 3 )
- 对于 t2 = b _ t1，新增 ( _ , 4 )，并将其与 b 和 t1 相连
- 对于 t2 = b \* t1，新增 ( t2 , 4 )
- 对于 t3 = - c，找到了 ( c , 1 )
- 对于 t3 = - c，找到了 ( - , 2 )
- 对于 t3 = - c，新增 ( t3 , 2 )
- 对于 t4 = b \* t3，找到了 ( b , 3 ) 和 ( t3 , 2 )
- 对于 t4 = b _ t3，找到了 ( _ , 4 )
- 对于 t4 = b \* t3，新增 ( t4 , 4 )
- 对于 t5 = t2 + t4，找到了 ( t2 , 4 ) 和 ( t4 , 4 )
- 对于 t5 = t2 + t4，新增 ( + , 5 ) ，并将其与 t2 和 t4 相连
- 对于 t5 = t2 + t4，新增 ( t5 , 5 )

### DAG图导出中间代码

输入：DAG 图

输出：化简后的中间代码序列

方法：

1. 初始化一个放置DAG图 **中间结点** 的队列。
2. 如果DAG图中还有中间节点未进入队列，则执行步骤3，否则执行步骤5
3. 选取一个尚未进入队列，但其**所有父节点均已进入队列**的中间节点n，将其加入队列；或选取**没有父节点**的中间节点，将其加入队列
4. 如果n的**最左子节点**符合步骤3的条件，将其加入队列；并沿着当前节点的最左边，**循环访问其最左子节点**，最左子节点的最左子节点等，将符合步骤3条件的中间节点依次加入队列；如果出现不符合步骤3条件的最左子节点，执行步骤2
5. 将中间节点队列**逆序输出**，便得到中间节点的计算顺序，将其整理成中间代码序列
