## I 问题描述

背包问题是一个经典的优化问题，它模拟了一个简单的决策场景：假设你有一个承重有限的书包，面前摆着多件重量和价值各不相同的物品。目标就是从这些物品中做出选择，将哪些物品装入书包，才能在书包的总重量不超过其最大承重限制的前提下，使得包内所有物品的总价值达到最高。这个问题本质上是在资源有限(如背包容量)的约束下，如何通过明智的选择和权衡，来实现收益(如总价值)的最大化。

## II 编程思路及方法

我编程的思路和方法如下：

1. 初始化问题数据并确定遗传算法参数(即种群规模、迭代次数交叉概率和变异概率)。课件上例题的种群规模只有4，效率很低，迭代很多次都无法到最佳结果，所以我改成了20。其他几个参数也做了适当的改动，使得效率更高。

2. 随机生成初始种群，是一个由随机数0和1组成的矩阵，矩阵行数即种群规模(因此每行代表一个初始个体)，列数即物品数量。

3. 计算初始种群中每个个体的适应度函数(注意使用罚函数来处理适应度)。

4. 轮盘赌选择。代码中的第一层循环是为了填充parent的第i行的新父代，第二层循环使得r落在哪个区间就选对应的初始方案。由于给适应度高的初始个体更大的选择概率，这一步可以使得初始种群中适应度高的个体进入父代。

5. 交叉操作，每次选择两个相邻的父代交叉，分别得到两个子代，最终子代数量会与父代数量相同。

6. 对所有子代进行变异操作。

7. 计算子代适应度，以便将父代和子代放在一起筛选。

8. 依据上一步计算的适应度从父代和子代的总体中保留适应度高的部分个体。

概括一下，就是先获得初始种群(N_p个)，用轮盘赌选出初始种群中适应度高的作为父代(N_p个，其中可能多次了选取初始种群中适应度高的某些个体，初始种群中适应度低的则可能未被选择过)，再用父代生成子代(N_p个)，再对子代进行变异(还是N_p个)。此时父代和子代加起来一共有2N_p个，从中选取适应度高的N_p个作为第二次循环的初始种群，如此循环下去会得到适应度越来越高的种群，直到得到最佳的答案。

## III 源代码

```matlab
clear, clc

%第一步：初始化问题数据并确定遗传算法参数(即种群规模、迭代次数交叉概率和变异概率)。课件上例题的种群规模只有4，效率很低，迭代很多次都无法到最佳结果，所以我改成了20。其他几个参数也做了适当的改动，使得效率相对课件上的参数较高。
cj = [91, 72, 90, 46, 55, 8, 35, 75, 61, 15, 77, 40, 63, 75, 29, 75, 17, 78, 40, 44];  % 价值
wj = [84, 83, 43, 4, 44, 6, 82, 92, 25, 83, 56, 18, 58, 14, 48, 70, 96, 32, 68, 92];   % 重量
W = 879;        % 背包容量
n = length(cj); % 物品数量

% 遗传算法参数
Np = 20;   % 种群规模
T =120;   % 迭代次数
pc = 0.8;  % 交叉概率
pm = 0.1;  % 变异概率

sum_gens = 0;        % 记录迭代次数的总值
genssuc = 0;         % 记录找到最佳值的次数

for test = 1:50
    % 第二步：随机生成初始种群，是一个由随机数0和1组成的Np行，n列的矩阵，包含Np个个体，每个个体中有n个物品。
    P = randi([0, 1], Np, n);

    best_found = false;  % 标记是否已找到最佳解
    first_best_gen = 0;  % 记录第一次找到最佳解的代数

    for generation = 1:T
        % 第三步：计算适应度函数。
        fitness = zeros(Np, 1);  % 生成行数与P相同，列数为1的矩阵，存储每个方案的适应度分数
        total_value = zeros(Np, 1); % 生成行数与P相同，列数为1的矩阵，存储每个方案的总价值
        total_weight = zeros(Np, 1); % 生成行数与P相同，列数为1的矩阵，存储每个方案的总重量

        for i = 1:Np
            % 计算总价值和总重量
            total_value(i) = sum(cj .* P(i, :)); % 行向量cj点乘P的第i行(第i种方案)，得到总价值
            total_weight(i) = sum(wj .* P(i, :));% 行向量wj点乘P的第i行(第i种方案)，得到总重量

            % 罚函数法处理约束
            if total_weight(i) <= W
                % 可行解，适应度=总价值
                fitness(i) = total_value(i);
            else
                % 不可行解，应用罚函数确定适应度，罚函数定义来自课件
                delta = min(W, abs(sum(wj) - W));
                penalty = 1 - abs(total_weight(i) - W) / delta;
                fitness(i) = total_value(i) * max(penalty, 0); % 确保适应度非负
            end
        end

        % 第四步：轮盘赌选择。第一层循环是为了填充parent的第i行的父代，第二层循环使得r落在哪个区间就选对应的初始种群个体
        parents = zeros(Np, n);  % 创建一个50×20的矩阵储存新的父代
        prob = fitness / sum(fitness);  % 轮盘赌中每个方案的概率

        for i = 1:Np
            cum_prob = 0; %新建变量并赋值为0，用来储存各个个体累加的选择概率
            for j = 1:Np
                cum_prob = cum_prob + prob(j);
                if rand <= cum_prob % rand是一个0到1的随机数，MATLAB自带，可以直接调用
                    parents(i, :) = P(j, :);
                    break;
                end
            end
        end

        %第五步：交叉操作，每次选择两个相邻的父代交叉，分别得到两个子代。
        offspring = parents; % 初始化子代

        for i = 1:2:Np-1
            if rand < pc % 如果随机数小于pc就交叉
                cross_point = randi([1, n-1]); % 交叉点是1到n-1间的随机数

                % 执行交叉
                parent1 = parents(i, :);
                parent2 = parents(i+1, :);

                offspring(i, :) = [parent1(1:cross_point), parent2(cross_point+1:end)];
                offspring(i+1, :) = [parent2(1:cross_point), parent1(cross_point+1:end)];
            end
        end

        %第六步：对所有子代进行变异操作。
        for i = 1:Np
            for j = 1:n
                if rand < pm
                    offspring(i, j) = 1 - offspring(i, j); % 翻转该位
                end
            end
        end

        %第七步：计算子代适应度，以便将父代和子代放在一起筛选。
        offspring_fitness = zeros(Np, 1);
        for i = 1:Np
            % 计算总价值和总重量
            ov = sum(cj .* offspring(i, :));
            ow = sum(wj .* offspring(i, :));

            % 罚函数法处理约束
            if ow <= W
                offspring_fitness(i) = ov;
            else
                delta = min(W, abs(sum(wj) - W));
                penalty = 1 - abs(ow - W) / delta;
                offspring_fitness(i) = ov * max(penalty, 0);
            end
        end

        % 第八步：依据上一步计算的适应度从父代和子代的总体中保留适应度高的部分个体。
        combined_pop = [P; offspring];
        combined_fitness = [fitness; offspring_fitness];

        % 按适应度排序
        [~, sorted_idx] = sort(combined_fitness, 'descend');

        % 选择前Np个个体
        P = combined_pop(sorted_idx(1:Np), :);

        % 显示当前代最佳解
        [best_fit, best_idx] = max(fitness);
        fprintf('迭代次数 %d: 最佳价值 = %.1f, 总重量 = %d\n', generation, total_value(best_idx), total_weight(best_idx));

        % 记录第一次达到最佳解1025/871的迭代次数
        if ~best_found && total_value(best_idx) == 1025 && total_weight(best_idx) == 871
            best_found = true;
            first_best_gen = generation;
        end
    end

    % 输出第一次达到最佳解1025/871的迭代次数
    if best_found
        fprintf('<strong>\n首次达到最佳价值1025、总重量871的迭代次数：%d\n</strong>', first_best_gen);
        sum_gens = sum_gens + first_best_gen;
        genssuc = genssuc + 1;
    else
        fprintf('\n未找到最佳解1025/871\n');
    end
end

ave_gens = round(sum_gens/genssuc);  % 找到最佳解的迭代次数的平均值
fprintf('<strong>\n达到最佳价值1025、总重量871所需迭代次数的平均值：%d\n</strong>', ave_gens);
```

## V 准确性的讨论与分析

这个遗传算法在解决背包问题方面表现非常出色。在120次迭代次数下，经过50次测试，它每次都能稳定找到已知的最优解(价值1025，重量871)，成功率高达100%，证明了算法的准确性。同时它的收敛速度很快，平均只需31代就能找到最优解，最快时只需13代，说明搜索效率很高。算法参数设置也很合理，种群规模20既保证了搜索效率又不会计算成本太高，交叉概率0.8能有效组合优良基因，变异概率0.1则在维持种群多样性和保护优良解之间取得了良好平衡。
